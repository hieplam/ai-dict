# Archive — shipped-card plans & specs

Historical record of per-card design specs and implementation plans for **shipped** roadmap
cards, moved here by the 2026-08-07 docs audit to keep `docs/superpowers/plans/` and
`docs/superpowers/specs/` navigable (they held ~130 files, most for long-shipped work).

- Nothing here is deleted — every file kept its content and git history (`git log --follow`).
- **Only SHIPPED cards belong here.** A card's pre-authored plan/spec pair (the 2026-07-16/17
  authoring wave) is a working input for a future campaign until the card ships — those pairs
  live in `plans/` / `specs/`, and move here only after ROADMAP marks the card shipped.
- Files still cited by frozen C3 facts, `.claude/workflows/*.js`, or source comments stayed in
  place in `plans/` / `specs/` regardless of shipped status; only externally-uncited history moved.
- Pre-move documents may reference each other by the old `docs/superpowers/plans|specs/...`
  paths; resolve those against this archive folder.
